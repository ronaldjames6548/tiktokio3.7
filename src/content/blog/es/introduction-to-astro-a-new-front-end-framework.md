Astro es un moderno marco de trabajo front-end que ofrece a los desarrolladores una forma más rápida de crear sitios web. Supone un interesante cambio de paradigma en la forma en que concebimos la creación de aplicaciones web modernas. 

## ¿Qué es Astro?

Astro es un nuevo tipo de generador de sitios web estáticos basado en JavaScript. A diferencia de otros marcos de trabajo populares como React, Vue y Angular, Astro no envía ningún código JavaScript de forma predeterminada. En su lugar, Astro solo envía HTML, CSS y la mínima cantidad de JavaScript que necesites. Esto se traduce en tiempos de carga más rápidos y un mejor rendimiento para tus aplicaciones web.

Astro está diseñado para aprovechar las características de los navegadores modernos, como HTTP/2 y los componentes de servidor. Esto te permite crear sitios altamente interactivos, sin el coste típico asociado al envío de grandes paquetes de JavaScript al cliente.


## Características principales de Astro


### No se envía JavaScript de forma predeterminada

Por defecto, Astro no envía JavaScript al cliente. Esto hace que tu sitio web sea rápido desde el primer momento. Sin embargo, no estás limitado a esto. Puedes añadir todo el JavaScript que quieras o necesites.


### Utiliza tu framework de JavaScript favorito

Una de las principales ventajas de Astro es su capacidad para trabajar con múltiples frameworks de JavaScript. Puedes utilizar componentes de React, Vue, Svelte y otros dentro del mismo proyecto. Esto te permite elegir la mejor herramienta para cada tarea, sin estar atado a una tecnología específica.


### Optimizado para SEO

El resultado de Astro es solo HTML, CSS y una cantidad mínima de JavaScript, lo que lo hace perfecto para la optimización en motores de búsqueda (SEO). Incluso puedes preprocesar tus páginas, lo que proporciona una carga inicial rápida y una excelente visibilidad en los motores de búsqueda.
