## Qu'est-ce qu'IgAnony ? ##
IgAnony est une application web qui permet aux utilisateurs de consulter les stories, les photos et les vidéos Instagram sans se connecter à un compte Instagram ni révéler leur identité. En saisissant le nom d'utilisateur d'un compte Instagram public, les utilisateurs peuvent accéder au contenu de ce compte et même le télécharger de manière anonyme.

## Comment utiliser IgAnony ? ##
   L'utilisation d'IgAnony est très simple :  
1. Rendez-vous sur le site web **IgAnony**.  
2. Saisissez le nom d'utilisateur Instagram du profil dont vous souhaitez consulter les stories.  
3. Parcourez les stories disponibles de manière anonyme.  
4. Si nécessaire, téléchargez le contenu directement sur votre appareil.  
**Remarque :** IgAnony ne fonctionne qu'avec les comptes Instagram publics.
