Ang Astro ay isang makabagong front-end framework na nagbibigay sa mga developer ng mas mabilis na paraan upang bumuo ng mga website. Nagdudulot ito ng isang kawili-wiling pagbabago sa paradigma sa kung paano natin iniisip ang pagbuo ng mga makabagong web application. 

## Ano ang Astro?

Ang Astro ay isang bagong uri ng JavaScript-based na static site generator. Hindi tulad ng ibang tanyag na framework gaya ng React, Vue, at Angular, ang Astro ay hindi nagpapadala ng anumang JavaScript bilang default. Sa halip, nagpapadala lamang ang Astro ng HTML, CSS, at kaunting JavaScript na kailangan mo. Nagbubunga ito ng mas mabilis na oras ng pag-load at mas mahusay na pagganap para sa iyong mga web app.

Ang Astro ay binuo upang samantalahin ang mga makabagong tampok ng browser, tulad ng HTTP/2 at server components. Pinapayagan ka nitong makabuo ng mga site na lubos na interaktibo, nang hindi kasama ang karaniwang gastos na kaakibat ng pagpapadala ng malalaking JavaScript bundle sa kliyente.


## Mga Pangunahing Tampok ng Astro


### Walang JavaScript na Ipinapadala nang Default

Sa default, walang JavaScript na ipinapadala ang Astro sa client. Dahil dito, mabilis na agad ang iyong site pagkabukas. Gayunpaman, hindi ka limitado dito. Maaari kang magdagdag ng gaano karaming JavaScript man ang gusto o kailangan mo.


### Gamitin ang Paborito Mong JavaScript Framework

Isa sa mga pangunahing lakas ng Astro ay ang kakayahan nitong gumana sa iba't ibang JavaScript framework. Maaari kang gumamit ng mga component mula sa React, Vue, Svelte, at iba pa sa loob ng iisang proyekto. Pinapayagan ka nitong piliin ang pinakamahusay na kasangkapan para sa trabaho, nang hindi nakatali sa isang partikular na teknolohiya.


### Magiliw sa SEO

Ang output ng Astro ay HTML, CSS, at kaunting JavaScript lamang, kaya perpekto ito para sa search engine optimization (SEO). Maaari mo ring i-prerender ang iyong mga pahina, na nagbibigay ng mabilis na paunang pag-load at mahusay na pagka-diskubre sa search engine.
