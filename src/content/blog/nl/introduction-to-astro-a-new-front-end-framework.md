Astro is een modern front-end framework dat ontwikkelaars een snellere manier biedt om websites te bouwen. Het zorgt voor een interessante paradigmaverschuiving in hoe we denken over het bouwen van moderne webapplicaties. 

## Wat is Astro?

Astro is een nieuw soort op JavaScript gebaseerde generator voor statische websites. In tegenstelling tot andere populaire frameworks zoals React, Vue en Angular, verstuurt Astro standaard geen JavaScript. In plaats daarvan verstuurt Astro alleen HTML, CSS en zo weinig JavaScript als je nodig hebt. Dit resulteert in snellere laadtijden en betere prestaties voor je webapps.

Astro is gebouwd om te profiteren van moderne browserfuncties, zoals HTTP/2 en servercomponenten. Hierdoor kun je zeer interactieve sites bouwen, zonder de gebruikelijke kosten die gepaard gaan met het versturen van grote JavaScript-bundels naar de client.


## Belangrijkste kenmerken van Astro


### Standaard wordt er geen JavaScript verstuurd

Standaard verstuurt Astro geen JavaScript naar de client. Dit maakt je site direct snel. Je bent hier echter niet aan gebonden. Je kunt zoveel JavaScript toevoegen als je wilt of nodig hebt.


### Gebruik je favoriete JavaScript-framework

Een van de belangrijkste sterke punten van Astro is de mogelijkheid om met meerdere JavaScript-frameworks te werken. Je kunt componenten van React, Vue, Svelte en andere binnen hetzelfde project gebruiken. Hierdoor kunt u de beste tool voor de klus kiezen, zonder gebonden te zijn aan een specifieke technologie.


### SEO-vriendelijk

De output van Astro bestaat alleen uit HTML, CSS en minimaal JavaScript, waardoor het perfect is voor zoekmachineoptimalisatie (SEO). U kunt uw pagina's zelfs vooraf renderen, wat zorgt voor een snelle eerste laadtijd en uitstekende vindbaarheid in zoekmachines.
